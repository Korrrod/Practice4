## Как запустить

После запуска start.bat появится виртуальное окружение, с помощью которого сайт откроется на http://127.0.0.1:8000

Остановить через Ctrl+C в консоли.

## Что нужно

- Python 3.8+
- Зависимости в requirements.txt, при первом запуске установятся сами

## Что умеет сайт

- Регистрация и вход
- Добавление путешествий с описанием, стоимостью и местами для посещения
- Оценки по 4 параметрам: транспорт, безопасность, населённость, растительность
- Поиск по названию, региону, году и сортировка по цене или оценке
- Личный список своих путешествий

## Что я сделал

1. Архитектура

Использовал Django и паттерн MTV. Это стандартный способ организации кода в Django. Модели описывают, как выглядит база данных, views обрабатывают запросы и содержат логику, templates отвечают за HTML-страницы.

2. Модель и база данных

Сделал одну основную модель. Она хранит название, описание, локацию, стоимость, список мест и четыре числовые оценки от 1 до 10. Каждое путешествие привязано к пользователю через ForeignKey. В качестве базы данных использовал SQLite, так как она встроена в Python и не требует отдельной установки.

3. Регистрация и авторизация

Реализовал регистрацию и вход. После входа Django сам отслеживает сессию. Страницы создания и редактирования путешествий защищены декоратором @login_required.

4. Поиск и фильтры

На главной странице можно искать по названию и описанию, фильтровать по региону и году, сортировать по дате, оценке или стоимости. Сортировка по оценке считается из суммы всех четырёх параметров.

5. Оценки

При создании путешествия выставляются оценки от 1 до 10 по четырём параметрам. На странице просмотра оценки показаны в виде цветных полосок.

6. Мои путешествия

Авторизованный пользователь видит отдельную страницу только со своими записями.

7. Шаблоны и интерфейс

Все страницы наследуются от одного базового шаблона base.html. Навигация, стили и общая структура описаны в одном месте. Использовал CSS-переменные для цветов, чтобы легко менять оформление.

## Что можно улучшить

- Все посты загружаются сразу одним списком. Если их будет несколько сотен, страница будет долго грузиться. Нужно добавить разбивку на страницы. В Django для этого есть встроенный пагинатор.

- Можно добавить редактирование своих путешествий со страницы сайта.

- Нет возможности оставить отзыв на чужое путешествие.

- У тестовых пользователей пароли "pass123" , что слишком просто. Django сам хэширует пароли при сохранении, но валидацию на минимальную длину и сложность лучше включить через AUTH_PASSWORD_VALIDATORS.
